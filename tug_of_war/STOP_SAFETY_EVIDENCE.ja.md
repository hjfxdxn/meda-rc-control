| 安全な停止方法の資料提出 | 本書と実験動画を提出する | 実測欄、判定欄、閲覧可能な動画リンク |
| 毎試合の開始5分前から現地確認 | 両停止機能と接続を確認する | 第7節のチェック欄 |

## 3. 停止機能の設計

### 3.1 状態遷移

`Settling → Clear → Armed → Pulling → Stopped`

1. 上電後、最低3秒間中立を出力する。
2. 有効な非対象音の窓を3回確認し、待機状態に入る。
3. 電子ホイッスルA音・B音に共通する特徴を連続2窓検出し、前方測距を確認する。
4. 測距が正常なら時間計測を開始し、前進指令と加速処理を実行する。
5. いずれかの停止条件が成立すると中立指令を出し、`Stopped`を保持する。障害物を取り除いても再始動せず、次の試験はRESET後に実施する。

LEDマトリクスは車号と状態を表示する。`−`は準備中、`✓`は合図待ち、`>`は駆動指令中、`×`は停止保持を示す。`✓`はESCの準備完了を電気的に検出した表示ではない。

### 3.2 時間による停止

```cpp
startedAt = micros(); // Immediately before the first forward command.

if (phase == Phase::Pulling && uint32_t(micros() - startedAt) >= RUN_US) {
  stopPull("10 second limit");
  return;
}
```

`RUN_US = 10000000`とし、主ループの先頭で監視する。300 msの加速時間もこの10秒に含む。最後の27 msは新しい超音波測定を開始しない設計で、測距待ちが時間判定を妨げることを抑える。

判定成立後に中立を要求するため、実際の信号更新にはループ、割込み、PWM更新の遅れがあり、その後にESC応答と機械的な停止時間が加わる。現状コードだけでは「車体が厳密に10秒以内に静止する」とは保証できない。実測で遅れを確認し、必要なら制動方法や停止指令時刻を見直す。

### 3.3 超音波による停止

```cpp
unsigned long width = pulseIn(ECHO, HIGH, ECHO_TIMEOUT_US);
float cm = width * 0.01715f;
return cm > STOP_CM && cm <= 400.0f;
```

| 測定状態 | 現在の動作 |
|---|---|
| 20 cmより大きく400 cm以下 | 駆動を許可する |
| 20 cm以下 | 中立を要求し停止保持する |
| 400 cm超、無回波、測定開始時のEcho HIGH | 中立を要求し停止保持する |

起動前にも同じ条件を確認する。起動前の異常でも停止保持となる。無回波を「前方に障害物なし」と扱う変更は、この版には含まれない。

超音波判定は10秒の経過を条件にせず、走行中おおむね60 msごとに実行する。ただし最後の27 msは時間停止を優先する。二つの判定は論理的に独立しているが、Arduino、電源、ESC、停止出力は共用する。別系統のハードウェア冗長停止ではない。

### 3.4 停止出力と限界

`stopPull()`は停止状態を保持し、ESCへ中立パルスを要求してLEDに`×`を表示する。逆転パルスによる能動制動は実装していない。中立時の制動力はESC設定と車両に依存する。

PWM関数の成功はArduino側の信号設定を示すもので、ESCの受信や実際の静止を確認するフィードバックではない。停止判定後にも動く場合は試験を中止し、動力電源を切って中立値、ESC設定、配線を確認する。

## 4. 計算書

### 4.1 時間監視

```text
Run duration = 10,000,000 us = 10.000 s
Echo timeout = 25,000 us = 25 ms
Final measurement guard = 25,000 + 2,000 = 27,000 us
No new ranging from elapsed time = 9.973 s
```

32ビット符号なし差分で経過時間を計算するため、10秒の測定中に`micros()`が一度桁あふれしても差分判定を継続できる。

```text
Actual stop time = command timer duration
                 + software / PWM update delay
                 + ESC response and mechanical stopping time
```

上式の追加時間は未測定である。中立指令時刻、最初の車輪回転時刻、実際の静止時刻を別々に記録する。

### 4.2 距離換算

コードは音速343 m/s相当の換算係数を使用する。

```text
Distance [cm] = echo duration [us] × 0.01715
Echo duration at 20 cm = 20 / 0.01715 ≈ 1,166 us
Echo duration at 400 cm = 400 / 0.01715 ≈ 23,324 us
Timeout equivalent distance = 25,000 × 0.01715 = 428.75 cm
```

428.75 cmは待ち時間から求めた換算値であり、センサがその距離を保証して測定できるという意味ではない。換算係数は固定で、温度補正は実装していない。

### 4.3 停止距離の評価

測定周期とタイムアウトだけを加えた応答時間の暫定見積りは、`60 + 25 = 85 ms`である。これはソフトウェア、割込み、PWM更新等を含む保証上限ではない。

```text
D_required = v × T_response + D_after_neutral + L_front + M
```

| 記号 | 定義・単位 |
|---|---|
| v | 障害物への接近速度 [m/s] |
| T_response | 停止距離しきい値の通過から中立信号までの時間 [s] |
| D_after_neutral | 中立信号から車体静止までに進む距離 [m] |
| L_front | センサ面から車体最前端までの前方距離 [m] |
| M | 停止後に確保する余裕距離 [m] |

必要条件は`0.20 m ≥ D_required`である。満たさない場合、20 cm設定のまま合格としない。停止しきい値、速度または制動方法を見直し、再試験する。

計算例（実測結果ではない）：`v = 1.0 m/s`、`T_response = 0.10 s`、`D_after_neutral = 0.06 m`、`L_front = 0.04 m`、`M = 0.05 m`なら、必要距離は`0.25 m`となり、20 cm設定では不足する。

## 5. 事前実験方法

最初に駆動輪を浮かせて信号・回転方向を確認し、その後、管理された試験場所で実際の路面・牽引負荷を用いて検証する。架空試験だけでは車体停止距離を証明できない。以下を各車で実施し、ばらつきを確認するため各条件を原則3回記録する（3回は本書の試験方針であり、提示された競技ルールの指定回数ではない）。

### A. 時間停止単独試験

1. 前方センサに十分な面積の紙板を正対させ、初回架空試験では50～100 cmに配置する。
2. 動作中も20 cmより大きく400 cm以下の有効回波を維持する。紙板の接近や回波喪失で先に停止した試行は、時間停止の証明に使用しない。
3. `✓`を確認して合図を鳴らし、駆動開始から停止まで連続撮影する。
4. `STOP 10 second limit`を確認する。PWM測定が可能ならD6の最初の前進パルスと中立復帰を記録する。
5. 車輪と車体の静止時刻を確認する。停止後に合図を再度鳴らしても再始動しないことを確認する。

### B. 超音波停止単独試験

1. RESET後、同様に紙板を50～100 cmに置いて自動開始する。
2. 10秒より十分前（例：開始3秒後）に紙板を20 cm以内へ移動する。回転部や車両進路に手を入れない配置で行う。
3. `STOP front obstacle or missing echo`と中立復帰、車輪・車体の停止を確認する。
4. このログは近距離と回波喪失を区別しないため、映像で紙板の正対状態と距離を示す。可能ならEcho信号も測定する。
5. 紙板を遠ざけても再始動しないことを確認する。
6. 実走行では停止位置を床面の目盛りで記録し、センサ位置と車体最前端の両方を測る。

### C. 補助確認

- 無回波で起動しないこと、走行中の回波喪失で停止すること。
- シリアルの`x`または`n`で停止すること。
- 上電時の中立保持で車輪が回転しないこと。
- A音とB音の双方で、合図から実際の車輪始動まで1秒以内であること。
- 電源、センサ、端子の固定状態を確認すること。

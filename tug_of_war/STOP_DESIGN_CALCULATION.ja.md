# 綱引き競技 停止機能設計書・計算書

作成日：2026年11月6日  
対象車両：81号車・82号車  
使用マイコン：Arduino UNO R4 WiFi  
対象プログラム：ローカル更新版（簡易音量RMS 50（81号車）／10（82号車）、20 cm未満のみ超音波停止）

## 1. 設計目的

綱引き競技の規定に対応するため、自動開始後の時間監視による停止と、超音波センサによる停止を実装した。いずれかの停止条件が成立した場合、ESCに中立信号を出力し、停止状態を保持する。

二つの停止条件は個別に判定する。ただし、マイコン、電源、ESCは共用しており、別系統のハードウェアによる冗長構成ではない。本書はプログラムの設計と計算根拠を示し、車両の停止性能は事前実験動画と併せて確認する。

## 2. 機器構成と設定

| 項目 | 81号車 | 82号車 |
|---|---|---|
| ESC | Tamiya TEU-105BK | Hobbywing QuicRun WP 1060 Brushed |
| ESC中立指令 | 1510 µs | 1530 µs |
| 始動指令 | 1240 µs | 1330 µs |
| 牽引指令 | 1200 µs | 1100 µs |
| 加速時間 | 300 ms | 300 ms |
| 操舵中立 | 1449 µs | 1550 µs |

上記はプログラムの設定値である。1100 µsをメーカー指定の最大出力値とするものではなく、中立と駆動方向は各車両のESC設定に合わせる。

| 接続先 | Arduino端子・信号 |
|---|---|
| ESC | D6、周期10000 µs（100 Hz） |
| ステアリングサーボ | D5、周期20000 µs（50 Hz） |
| マイクのアナログ出力 | A0 |
| 前方HC-SR04 | Trig：D8、Echo：D12、電源5 V、共通GND |

## 3. 動作の流れ

1. 電源投入後、ESCへ最低3秒間中立信号を出力する。
2. RMSが各車のしきい値未満となる約50 msの区間を連続3回確認し、合図待ち状態に入る。
3. 約50 msの区間でRMSが各車のしきい値以上となる状態を連続2回検出し、前方の測距結果を確認する。
4. 条件成立時に時間計測と前進指令を開始する。300 msで牽引指令へ移行する。
5. 時間または超音波の停止条件が成立すると中立指令を出力し、停止状態を保持する。

LEDマトリクスには車号と状態を表示する。`−`は準備中、`✓`は合図待ち、`>`は駆動指令中、`×`は停止保持を示す。

## 4. 時間監視による停止

最初の前進指令の直前に`micros()`で開始時刻を記録する。主ループの先頭で経過時間を確認し、10000000 µs以上となった時点で停止処理を実行する。

```cpp
startedAt = micros();

if (phase == Phase::Pulling && uint32_t(micros() - startedAt) >= RUN_US) {
  stopPull("10 second limit");
  return;
}
```

```text
RUN_US = 10,000,000 us = 10.000 s
```

300 msの加速時間も10秒に含む。経過時間は32ビット符号なし整数の差分で求めるため、計測中のタイマの桁あふれに対応する。

超音波の応答待ち時間は最大25000 µsとし、終了直前の27000 µsは新たな測距を開始しない。

```text
Guard time = 25,000 + 2,000 = 27,000 us
Final ranging cutoff = 10.000 - 0.027 = 9.973 s
```

これにより、終了直前の測距待ちによる時間判定の遅れを抑える。実際の中立信号更新にはループ処理やPWM更新の遅れがあり、さらにESCと車体の応答時間が加わる。10秒到達時の中立要求と機械的な静止は区別し、実験で停止時刻を評価する。

## 5. 超音波センサによる停止

前方に設置したHC-SR04で、おおむね60 msごとに測距する。時間停止の成立を待たず、次の条件で停止を要求する。ただし、終了直前の27 msは時間監視を優先する。

| 測定結果 | 動作 |
|---|---|
| 20 cm以上 | 駆動を許可する |
| 回波があり20 cm未満 | 停止する |
| 400 cmを超える、回波を取得できない | 距離不明として駆動を許可する |
| 測定開始時にEcho端子がHIGH | 距離不明として駆動を許可する |

同じ測距確認を始動前にも行う。無回波では停止しない。センサ断線も検出できないため、試合前に紙板による停止試験を行う。

```cpp
unsigned long width = pulseIn(ECHO, HIGH, ECHO_TIMEOUT_US);
float cm = width * 0.01715f;
return width == 0 || cm >= STOP_CM;
```

## 6. 距離と停止余裕の計算

### 6.1 超音波の距離換算

コードでは音速343 m/s相当の係数を用い、往復時間から片道距離を求める。

```text
Distance [cm] = echo duration [us] × 0.01715
Echo duration at 20 cm = 20 / 0.01715 ≈ 1,166 us
Echo duration at 400 cm = 400 / 0.01715 ≈ 23,324 us
```

400 cm相当の回波時間は25000 µsのタイムアウト以内となる。換算係数は固定であり、プログラムによる温度補正は行っていない。

### 6.2 停止距離

測定周期とタイムアウトの合計は次のとおりである。

```text
60 ms + 25 ms = 85 ms = 0.085 s
```

85 msはこの二つの設定から求めた見積りであり、割込みやPWM更新などを含む実際の最大応答時間ではない。停止しきい値は、応答中の移動距離、中立後の移動距離、車体寸法および余裕を考慮して決める。

```text
D_required = v × T_response + D_after_neutral + L_front + M
```

| 記号 | 内容 |
|---|---|
| v | 障害物への接近速度 [m/s] |
| T_response | しきい値通過から中立信号までの時間 [s] |
| D_after_neutral | 中立信号から静止までの移動距離 [m] |
| L_front | センサ面から車体最前端までの前方距離 [m] |
| M | 停止後に確保する余裕距離 [m] |

現在の設定は`STOP_CM = 20`である。必要条件は`0.20 m ≥ D_required`となる。実験でこの条件を満たさない場合、停止距離のしきい値、駆動出力または制動方法を調整する。

## 7. 停止処理と再始動防止

停止処理ではESCに中立信号を要求し、状態を`Stopped`に変更する。以後は新しい駆動指令を出さない。紙板を取り除いた場合や再びホイッスルが鳴った場合も再始動せず、次の運転にはRESETを必要とする。

中立指令は駆動停止の要求であり、逆転パルスによる能動制動は実装していない。中立時の制動特性はESC設定に依存するため、車輪と車体の実際の停止を確認する。また、PWM設定の成功はESCの受信や機械的停止を検出するフィードバックではない。

補助停止として、115200 baudのシリアル通信で`x`または`n`を受信した場合にも停止処理を実行する。時間停止と超音波停止は、PCへの接続なしで動作する。

## 8. 事前実験と動画による確認方法

### 時間停止の確認

前方に有効な反射目標を維持し、超音波停止を発生させずに自動開始する。開始から停止まで連続撮影し、`STOP 10 second limit`の出力と車輪・車体の静止を確認する。D6のPWM測定を併用することで、最初の前進信号から中立復帰までの時間を確認する。

### 超音波停止の確認

初回の架空試験では紙板をセンサ正面50～100 cmに置いて開始する。10秒より十分前に紙板を20 cm未満へ接近させ、中立復帰と停止を確認する。停止後に紙板を遠ざけても再始動しないことを確認する。距離はセンサ面から測る。

### 実走行での停止距離の確認

架空試験後、実際の路面と牽引負荷を考慮した試験を行う。車号、センサ、紙板、車輪、車体全体および距離目盛りを撮影し、中立後の移動距離と停止後の余裕を評価する。81号車と82号車は個別に検証する。

動画の時間計測には`経過時間 = フレーム差 / fps`を用いる。60 fpsでは1フレームが約16.7 msであり、時間判定にはフレーム選択の誤差も考慮する。LEDやログだけで機械的停止を判定せず、実際の車輪と車体の動きを確認する。

## 9. 試合前の確認

試合開始5分前までに集合し、TA/SAによる停止機能の確認を受ける。車号とプログラムの一致、端子の固定、電源、中立動作、二つの停止機能、停止後の再始動防止およびカラビナの接続を確認する。提出資料は本設計書・計算書と事前実験証明動画を組み合わせ、機能の実装と実車の停止動作を示す。

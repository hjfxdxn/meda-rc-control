Upload microphone_test.ino, then close the Arduino IDE Serial Monitor and Serial Plotter. Open this file in desktop Chrome or Edge, click Connect Arduino, and select the board port. The distance alert is for monitoring only and does not control the motor.

Arduino detects the start signal using A0; this page only displays the result. After power-on, keep quiet for about 1 second, then play either start sound for about 1 second. START and the onboard LED remain latched until reset; reset itself does not trigger a start. Similar sustained tones may also trigger detection, so test in the actual environment.
